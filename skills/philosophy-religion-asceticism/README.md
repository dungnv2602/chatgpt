# Philosophy, Religion & Asceticism — Scholarly Research Expert

Version 4. A reusable Agent Skill for rigorous, source-led work in philosophy, religious
studies, theology, asceticism, monasticism, and contemplative traditions.

## Contents

- `SKILL.md` — required skill manifest and core instructions.
- `references/source-standards.md` — scholarly source hierarchy and evaluation.
- `references/research-method.md` — discipline-specific methods.
- `references/answer-patterns.md` — adaptable answer structures.
- `references/schopenhauer-44-week-curriculum.md` — a complete 44-week advanced Schopenhauer reading and study pathway.

## Use in ChatGPT

This package follows the Agent Skills directory format: a folder containing a
`SKILL.md` file with YAML front matter (`name` and `description`) and supporting
reference files.

If Skills are enabled for your ChatGPT account or workspace:

1. Open ChatGPT and open the sidebar.
2. Select **Plugins**, then open the **Skills** tab.
3. Choose **Create** → **Upload from your computer**.
4. Select this ZIP file and wait for ChatGPT's security scan.
5. Review any **Needs Review** notice, then install/enable the skill if offered.
6. Invoke it explicitly with `@philosophy-religion-asceticism`, or ask a
   relevant question and allow automatic skill selection.

The exact labels and availability can vary by plan, workspace, and app surface.
OpenAI's current Help Center lists Skills in ChatGPT for eligible Business,
Enterprise, Healthcare, and Edu users, subject to workspace settings. If you
are on a plan or workspace where the Skills tab or upload option is absent,
you cannot install this ZIP as a standalone ChatGPT Skill there.

On Android/iOS, first check whether **Plugins → Skills** is visible in your
sidebar. If it is not, use ChatGPT on the web at chatgpt.com and check the same
menu. The feature still may not be enabled for your account. Uploading a file
into an ordinary chat does not install a Skill.

## Workaround if Skills upload is unavailable

You can still use the skill's instructions manually:

- Start a chat and attach this ZIP (or paste the contents of `SKILL.md`).
- Tell ChatGPT: "Use the attached Philosophy, Religion & Asceticism skill as
  the standing methodology for this conversation. Follow its source standards
  and cite substantive claims."
- For future conversations, keep the `SKILL.md` text in a note so you can
  reattach or paste it. This is a manual workaround, not a permanent skill
  installation.

You can also place the extracted skill folder in a supported Codex skills
directory if you use Codex. That is a separate product workflow from installing
a ChatGPT Skill.

## Version 4 update

Version 4 adds a dedicated 44-week Schopenhauer curriculum. It integrates the
Cambridge Edition primary texts with the user's established specialist
secondary reading, defines a 4–6-hour weekly study rhythm, and includes phase
checkpoints, written outputs, and safeguards against unverified chapter or page
references. The broader research standards and mandatory three-part book
evaluation rule from version 3 are retained.
