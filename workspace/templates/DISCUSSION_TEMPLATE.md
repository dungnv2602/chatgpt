# Discussion Register Template

Use this template for the active conversation's discussion register. Keep entries concise, factual, and traceable.

## Current Step

- **YYYY-MM-DD HH:MM TZ:** State the active initialization or work step, completed actions, verified evidence, blockers, and next action. Do not claim validation that was not performed.

## Open Discussions

- **YYYY-MM-DD:** Record unresolved decisions, constraints, approvals, and deferred matters. Remove an item only when its disposition is recorded.

## Reports

- **YYYY-MM-DD HH:MM TZ:** Record completed work, exact paths, commit identifiers, readback evidence, checks performed, and limitations. Keep reports factual and distinguish repository verification from hosted CI validation.

## Entry conventions

- Use an explicit date. Include a 24-hour time and UTC offset when the time is known.
- Link repository records with relative Markdown links when a stable path exists.
- Preserve user decisions and constraints accurately. Do not convert proposals into approvals.
- Separate current execution state, unresolved discussion, and completed reports.
- Do not claim a file write, commit, readback, test, or CI result unless the corresponding action succeeded.
