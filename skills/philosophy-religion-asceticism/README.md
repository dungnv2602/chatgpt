Version 4. This Agent Skill supports source-led research in philosophy, religious studies, theology, asceticism, monasticism, and contemplative traditions.

## Use in ChatGPT

This package follows the Agent Skills directory format. It contains a `SKILL.md` file with YAML front matter. The required fields are `name` and `description`.

If Skills are enabled for your ChatGPT account or workspace:

1. Open ChatGPT and open the sidebar.
2. Select **Plugins**. Then open the **Skills** tab.
3. Select **Create** → **Upload from your computer**.
4. Select this ZIP file. Wait for the ChatGPT security scan.
5. Review any **Needs Review** notice. Then install or enable the skill if the option appears.
6. Invoke the skill with `@philosophy-religion-asceticism`, or ask a relevant question and allow automatic skill selection.

The exact labels and availability can vary by plan, workspace, and app surface.

OpenAI's current Help Center lists Skills in ChatGPT for eligible Business, Enterprise, Healthcare, and Edu users. Workspace settings may also affect access.

If your plan or workspace does not show the Skills tab or upload option, you cannot install this ZIP as a standalone ChatGPT Skill there.

On Android or iOS, first check whether **Plugins → Skills** appears in the sidebar. If it does not, open ChatGPT on the web at chatgpt.com and check the same menu.

The feature may still be unavailable for your account. Uploading a file into an ordinary chat does not install a Skill.

## Workaround if Skills upload is unavailable

You can still use the skill's instructions manually:

- Start a chat. Attach this ZIP or paste the contents of `SKILL.md`.
- Tell ChatGPT: "Use the attached Philosophy, Religion & Asceticism skill as the standing methodology for this conversation. Follow its source standards and cite substantive claims."
- For future conversations, keep the `SKILL.md` text in a note. Reattach or paste it when needed. This method does not install a permanent skill.

You can also place the extracted skill folder in a supported Codex skills directory if you use Codex. This is separate from installing a ChatGPT Skill.

## Version 4 update

Version 4 adds a dedicated 44-week Schopenhauer curriculum. It integrates the Cambridge Edition primary texts with the user's established specialist secondary reading.

The curriculum defines a 4–6-hour weekly study rhythm. It also includes phase checkpoints, written outputs, and safeguards against unverified chapter or page references.

Version 4 retains the broader research standards and mandatory three-part book evaluation rule from Version 3.
