# Drawing Skill

Navigation and concise overview for the Drawing Skill. The [canonical skill](SKILL.md) owns execution rules and activation. Load it only when activated.

## Scope

Image generation, direct editing of a specific source image, visual iteration and drawing-session workflows.

## Modes

- **Realistic:** photographic rendering, natural materials, plausible lighting and anatomy.
- **Vintage:** painterly, illustrative or print-inspired rendering.

The active session brief selects the mode. Use the session brief and canonical skill for operation selection, constraints and continuity.
