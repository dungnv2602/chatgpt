# Repository Analysis

Navigation for evidence-based repository reviews.

## Canonical format

- [ANALYSIS_TEMPLATE.md](../../.agent/skills/the-worker/assets/ANALYSIS_TEMPLATE.md) — template for fixed-commit snapshots.
- Quarterly: `ANALYSIS-YYYYQn.md`.
- Event review: `ANALYSIS-YYYYQn-short-event-name.md`.

## Ownership

- The Worker and [Decision Governance](../../.agent/skills/the-worker/references/decision-governance.md) own review triggers, scope, evidence, methods, classification, confidence, recommendations and closeout.
- Analysis describes repository state. It is not an implementation plan or issue backlog.
- Drafts propose decisions. Accepted ADRs govern implementation. Tasks track approved work. The CI Ledger owns active diagnostics.
- Cite Ledger findings rather than duplicating them.
- Keep completed snapshots in this folder. Do not create an analysis archive.
