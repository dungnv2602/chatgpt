# Novel Templates

These reusable templates belong to the Romantic Storyteller skill. Store them in this `assets/templates/` directory.

The novel workspace at `area/novel/` owns project records and workflow documentation. It links to these skill-owned assets. Do not create a project-local `templates/` directory or duplicate these files.

## Current templates — Version 1.1

Use these templates for new records and material revisions:

| Document type | Template | Notes |
|---|---|---|
| Novel | [novel-v1.1.md](templates/novel-v1.1.md) | One foundation record per novel |
| Character Profile | [character-profile-v1.1.md](templates/character-profile-v1.1.md) | Optional when the novel summary is sufficient |
| Open Discussion | [open-discussion-v1.1.md](templates/open-discussion-v1.1.md) | One active register per novel |
| Development Outline | [development-outline-v1.1.md](templates/development-outline-v1.1.md) | Optional focused planning record |
| Story Arc | [arc-v1.1.md](templates/arc-v1.1.md) | One record per story arc |
| Scene | [scene-v1.1.md](templates/scene-v1.1.md) | Contains the complete scene prose |
| Illustration Note | [illustration-note-v1.1.md](templates/illustration-note-v1.1.md) | Records the visible asset and narrative context |
| Illustration Prompt Record | [illustration-prompt-v1.1.md](templates/illustration-prompt-v1.1.md) | Records exact prompts and chronological attempts |

## Historical templates — Version 1.0

Keep these for legacy reference. Do not use them for new records:

- [Novel](templates/novel-v1.md)
- [Story Arc](templates/arc-v1.md)
- [Scene](templates/scene-v1.md)

## Ownership and maintenance

- The Romantic Storyteller skill owns these templates.
- The novel workspace README links to the current and historical templates.
- The novel workflow defines when to create each record and how to preserve canon.
- Update the affected templates, this index, `area/novel/README.md`, `area/novel/WORKFLOW.md`, and the skill's novel workflow reference together when a format changes.
- Follow the repository document catalog and skill-authoring standard for template changes.
