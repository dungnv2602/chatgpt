# Discussion Register Template

Use this structure for the active conversation register. The Worker owns the register's operating contract.

## Current Step

- **YYYY-MM-DD HH:MM TZ:** Concise current action and next verification.

## Open Discussions

- **YYYY-MM-DD:** Unresolved decisions, constraints, approvals, or deferred matters. Remove only after recording disposition.

## Reports

- **YYYY-MM-DD HH:MM TZ:** Completed work, changed paths, commit identifiers, readback, checks, and limitations.
