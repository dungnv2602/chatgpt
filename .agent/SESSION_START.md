# Session Start

Initialization is conditional. Do not load project instructions, skills, or references at the start of a new conversation.

The sole session-start cue is **`/start`**. Ignore quoted, discussed, or hypothetical uses of the cue.

When the user gives `/start` as an instruction, first read [the Workflow Map](WORKFLOW_MAP.md) for the workflow overview. Then read and follow [The Worker](skills/the-worker/SKILL.md) for initialization, operational rules, loading gates, and progressive reference routing. Do not load The Worker or task-related references before the map. The separate `/map` cue displays the map only and does not initialize.

A specialist-role request is not a session-start cue. Do not initialize foundational or specialist instructions without their required explicit cue and prerequisite checks.
