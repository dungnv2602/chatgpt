# Drawing Style Guide

Use one dominant mode per image unless the user explicitly requests a controlled
hybrid.

## Realistic Mode

**Core test:** Would a viewer initially read the image as a photograph or
natural cinematic capture?

### Rendering cues
- Credible light falloff, contact shadows, reflections, and ambient illumination.
- Natural skin texture, hair strands, fabric weave, glass, metal, and wood.
- Physically plausible perspective, depth, anatomy, weight, and posture.
- Restrained color grading and believable depth of field.
- Natural facial expressions and gestures.

### Variants
Candid lifestyle photography, cinematic natural-light photography, editorial
portraiture, fine-art photography, or studio portraiture.

### Common failures
Plastic skin, excessive HDR, synthetic highlights, impossible reflections,
weightless anatomy, or an unintended illustrated surface.

## Vintage Mode

**Core test:** Does the image visibly express a crafted, nostalgic visual
language through medium, texture, palette, or print character?

Vintage is not a synonym for sepia. A warm, softly painted picture may be Vintage
even when it uses full color and has no paper damage.

### Shared cues
- Brush texture, pigment layering, paper grain, print texture, or analog grain.
- A considered warm, muted, earthy, dusty, or period-informed palette.
- Gentle tonal transitions and intentional simplification.
- Nostalgia without sacrificing facial readability or anatomy.
- A coherent medium rather than contradictory effects.

### Substyles

| Substyle | Defining visual language | Avoid |
|---|---|---|
| Painterly storybook | Soft hand-painted forms, delicate brushwork, warm light | Cartoon exaggeration |
| Classic oil painting | Layered pigment, tonal depth, directional brushwork | Plastic digital gloss |
| Watercolor | Transparent washes, luminous paper, soft edges | Muddy uncontrolled blooms |
| Gouache | Matte opaque color, graphic painted shapes | 3D bevels and gloss |
| Vintage editorial | Elegant line, limited palette, print-like composition | Generic clip-art |
| Retro print | Screenprint, lithograph, halftone, restrained ink texture | Random grunge |
| Analog-photo vintage | Film grain, faded color, period-informed photographic character | Painterly brushwork unless requested |

### Palette and surface
Cream, ivory, faded blue, muted rose, amber, olive, tobacco, and earth tones
are optional tools, not mandatory ingredients. Use sepia or monochrome only when
asked or historically appropriate. Paper aging, scratches, cracks, and heavy
grain are optional effects, not default markers.

### Historical example — not a current-session default
An earlier cozy-bedroom image was classified as **Vintage Mode → Painterly
Storybook**, based on its hand-painted-looking surfaces, brush texture, gentle
forms, and nostalgic cream-and-amber atmosphere. This is a historical example
only. It does not establish the mode, palette, scene, or visual direction for a
new drawing session; the active session brief always controls those choices.

## Choosing a mode

| User language | Recommendation |
|---|---|
| Photorealistic, lifelike, camera-like, natural photo | Realistic |
| Painting, hand-painted, storybook, watercolor, oil, gouache | Vintage |
| Nostalgic, retro, aged print, old film | Vintage, then choose a print or analog-photo substyle |
| Warm, cozy, cinematic | Not enough by itself; infer from other cues or ask |
| Realistic illustration | Ask which should dominate if unclear |
