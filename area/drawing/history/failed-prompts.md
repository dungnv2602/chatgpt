# Historical Failed Prompt Index

**Scope:** Drawing prompts archived before 19 November 2026 in this folder.

This index includes rejected prompts and prompts whose generated outputs missed defining requirements. “Failed” describes the attempt against its recorded brief; it does not mean the image was necessarily unattractive. The full authored text remains in each linked chronological or standalone source record.

## Classification rules

- **Rejected:** The tool returned a refusal and no image.
- **Missed target:** An image was returned, but one or more defining requirements were not met.
- **Partial match:** Some requested features appeared, but the result was not a complete match.
- **Unverified source edit:** The prompt intended an edit, but the returned metadata or result did not confirm that the supplied source was edited.
- **Prompt text unavailable:** The archive confirms an unsuccessful attempt but does not preserve recoverable authored wording. No prompt is reconstructed.
- User approval is retained as recorded. Attempts explicitly designated successful by the user are listed in the successful prompt index even when technical caveats remain.
