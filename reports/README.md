# Reports

Single entry point for generated repository reports.

- [lint_reports/](lint_reports/README.md): STE lint findings, baselines, and fingerprints.
- [gh_ac_reports/](gh_ac_reports/README.md): GitHub Actions workflow, job, step, log, annotation, and artifact diagnostics.
- [triage/](triage/README.md): shared cross-family issue ledger.

Resolved report files move to `archive/reports/` and are retained under the shared 90-day individual-file policy in [the archive guide](../archive/README.md). No `reports/archive/` or separate report-retention workflow exists.
