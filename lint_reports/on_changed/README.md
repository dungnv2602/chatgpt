# Changed-document Lint Reports

Canonical reports for the changed-document STE workflow. Incremental runs and full-audit fallbacks both belong here. The execution mode field distinguishes them. The latest report is at `latest-lint-report.md` and `latest-lint-report.json`. Historical evidence lives in `history/<run-id>/`.

The generator consumes the canonical Markdown template and JSON Schema in `skills/asd-ste100/assets/`. Do not edit generated reports. Update the template, schema, generator, regression tests, and Document Type Catalog together when the format changes.
